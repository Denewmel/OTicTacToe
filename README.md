# OTicTacToe

Классическая игра "Крестики-нолики", написанная на flutter с открытым исходным кодом.
Цель данного проекта - реализовать простую классическую игру с открытым исходным кодом для саморазвития и пополнения портфолио.

## Особенности
### Два режима игры
  1. Игра с другом на одном устройстве
  2. Игра против компьютера
### Разные уровни сложности
  - **Лёгкий** - компьютер ходит в случайные поля.  
  - **Нормальный** - компьютер блокирует твои выйгрышные линии, мешая победить.  
  - **Невозможный** - компьютер играет идеально.
### Минималистичный интерфейс
  Никакой рекламы, ничего лишнего - только игра.
